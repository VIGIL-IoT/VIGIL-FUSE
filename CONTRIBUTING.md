# Contributing

FUSE is a source-available VIGIL Project. Its current custom license is not an open-source license and restricts redistribution of copies and modified versions. Public contribution rights and contributor terms have not been established. Before preparing a public fork or submitting a patch that would publish modified code, contact the repository owner for written guidance. Do not assume a pull request grants rights that the license does not state.

For maintainers working on an authorized local change, follow the [development guide](docs/contributing.md), the [rule-development contract](docs/rule-development.md), and the [release process](docs/release-process.md). Keep scan evidence, credentials, private keys, and proprietary target files out of public issues and commits.

Security reports must follow [SECURITY.md](SECURITY.md), not a public issue.
