FUSE / OPTIONAL BINARY ANALYSIS

Ghidra extends the firmware path

FUSE stages one selected file, then runs only the requested analyzer. Ghidra exports bounded evidence for FUSE to validate and normalize. Binwalk remains a separate signature-only stage.

FUSE only runs Ghidra when requested. Ghidra parses the selected binary with the current user's permissions. Read the integration guide for limits, statuses, and safe-use guidance.
