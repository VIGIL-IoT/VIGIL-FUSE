# Contributing

FUSE is source-available under the [VIGIL-FUSE Restricted Use License](LICENSE). That license does not grant permission to redistribute FUSE or publish modifications. Public code contributions are paused while project ownership and contribution policy are reviewed. Issues and discussion are welcome. Obtain written permission from the repository owner before preparing a public code patch; opening an issue or pull request does not itself grant permission.

For maintainers working on an authorized local change, follow the [development guide](docs/contributing.md), the [rule-development contract](docs/rule-development.md), and the [release process](docs/release-process.md). Keep scan evidence, credentials, private keys, and proprietary target files out of public issues and commits.

Security reports must follow [SECURITY.md](SECURITY.md), not a public issue.
