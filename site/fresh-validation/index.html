Scope and limits

  • The pinned corpus and selection protocol are described in the generated report.
  • Skipped inputs and legacy text decoding are disclosed in the coverage summary.
  • Optional analyzer context may be partial even when source file scanning completed.
  • Firmware candidates are filename and size inventory only. Firmware bytes were not analyzed.
  • Hardware matches identify filenames only. No schematic or PCB security analysis was performed, and no netlist was parsed.
  • No build resolution, runtime or device validation, or dependency advisory analysis was performed.
  • IoTGoat includes OpenWrt source that is also present in the separate OpenWrt snapshot. Raw scope totals are not deduplicated.
