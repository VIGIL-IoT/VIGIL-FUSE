## Evidence boundaries

The full suite result applies to the current local working tree at audit time. FUSE CI runs #260 and #263 separately verify the original synthetic performance smoke path and its metadata update. The cross-platform report set applies to four selected scopes at pinned commits on one hosted runner for each of Linux, Windows, and macOS. It verifies consistent checkout byte totals, selected-file coverage, and candidate-signal counts across those reports, not detector accuracy or controlled relative speed. External-tool adapter tests do not replace testing each installed executable and version. Repository scan counts and performance results apply to their pinned inputs and do not establish vulnerability prevalence or general scan speed.
