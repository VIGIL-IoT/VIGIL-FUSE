From project tree to reviewable output.

Install the package from the repository once. Each scan writes the report set to the folder you choose.

  1. Install once

    From the FUSE repository root, install the local package with Python 3.11 or newer.

  2. Choose a project

    Scan selected source and configuration files, or choose an embedded profile to expand file discovery.

  3. Review each signal

    Find the affected file, evidence, explanation, potential impact, confidence and remediation together.

  4. Share the reports

    Keep readable text, machine-readable JSON and SARIF side by side in the output folder.

  • findings.sariftool interchange

The command creates all three reports together.

Native rules inspect selected text and configuration files. Optional Syft and OSV-Scanner adapters add component inventory and advisory matching. Baseline review tracks new, persistent and resolved findings; reasoned suppressions remain counted, and incomplete scans never mark missing findings resolved. Optional Binwalk identifies firmware signatures only; FUSE does not extract or execute firmware.

Signals stay inside their evidence.

Source inspectionFUSE does not validate credentials, contact endpoints or claim that a flagged code path is reachable.

Firmware intakeBinwalk signature identification is partial coverage. Firmware extraction and execution are outside the current workflow.
